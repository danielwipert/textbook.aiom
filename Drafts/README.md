# Drafts

Working drafts for the manuscript, one directory per chapter plus the three Part
cumulative cases (`Case_Part_I` to `Case_Part_III`). Build tooling, the design
system and the project specs stay at the repository root.

## The live text never moves

Each chapter has ONE live text, and it stays in `00_Stage0_Draft/` for the whole
life of the chapter (Decision 50). The other folders hold the artifacts a step
produced: packets, renders, second-model returns, reports. They never hold a
competing copy of the chapter. Supersede and delete, never fork.

## Three layouts are in force, one per process

A completed unit keeps the process it was completed under.

**Chapter 1** is locked under Process v2 and keeps its v2 folders.

**Chapter 2** is locked under Process v3 and keeps its thirteen v3 folders.

**Chapter 3 onward, and the three Part cases**, run Process v4 (Decisions 75 to
81, migrated 2026-09-30 by `renumber_stage_folders_v4.py`). The Stage labels are
kept from v3 so the tools bind unchanged; the prefix gives the real order.

generated by `python3 gen_checklists.py N`.

## Conventions

- Chapter folders are zero-padded (`Ch01` to `Ch15`) so they sort in reading order.
- Empty folders carry a `.gitkeep` so the structure persists in git.
